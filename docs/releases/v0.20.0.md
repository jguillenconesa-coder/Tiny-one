# Pocket One 0.20.0 — Filter 246

**set 3 → FILTER 246** añade el filtro reconstruido al bus de salida, con Cutoff,
Resonance/Follow, Mode y Drive, Value FX, MIDI, automatización y guardado. Esta
inserción afecta sintetizador, cinta, entrada y master; sigue siendo ruteo propio.
[Guía y contrato](../filter246-native.md).

El núcleo coincide en **262.144 muestras**, 4.096 estados/displays completos y sus
194 coeficientes generados. Reproducción independiente idéntica. Conserva el pico
previo de todo el bloque y la aritmética/no linealidades observadas.

El plugin comunica ahora una **latencia fija de aproximadamente 1,5 ms**, incluso
en bypass: 65/71/141 muestras a 44,1/48/96 kHz. Evita modificar PDC al activar el
filtro y mantiene el bypass exacto retrasado. El adaptador de tasa, DC, guardia de
silencio y mezcla son propios; no se certifica igualdad acústica con el OP-1.

72 suites Linux y 228 cargas de callback, sanitizadores, estados, UI/proxies,
MIDI y audio independiente del bloque. [Registro](v0.20.0-validation.json).
Nitro conserva un bloqueo concreto de tabla L1 protegida; no se añaden coeficientes
inventados ni presets originales. La comprobación nativa corresponde al CI de
esta entrega; Ableton real sigue pendiente. No se publica release automáticamente.
