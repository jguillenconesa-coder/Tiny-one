# Pocket One 0.36.0 — controles y voz del sampler

SAMPLER 246 expone sus ocho campos con loop/fine independientes, dirección y
volumen. FINE / GAIN cambia el banco de mandos; la pantalla muestra cuatro límites
y unidades ms/us/%. Set 2 incorpora ADSR 246 opcional y Poly/Mono/Legato/Glide,
con automatización, proyectos, slots, clipboard y proxies MIDI sin editor abierto.

El lector conserva su oráculo original de 4096 bloques/524288 muestras. La nueva
composición lector + ADSR se compara en 32768 muestras, estados y dither. El orden,
clock, allocator/eventos/portamento, LOOP gate y salida siguen siendo propios;
no se afirma reconstruir la voz original completa ni equivalencia acústica.
