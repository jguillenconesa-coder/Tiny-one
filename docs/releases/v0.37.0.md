# Pocket One 0.37.0 — moduladores del sampler

SAMPLER 246 incorpora Value de ocho destinos, Random Instrument/ADSR y Tremolo,
con estado/proyectos/slots/clipboard, automatización y proxies sin editor abierto.
El banco de set 1 selecciona los cuatro colores de Value; ADSR requiere 246 ENVELOPE.
Se respeta el acoplamiento original entre límites coarse y fracciones del loop.

**8192 callbacks originales** de Value/Random coinciden en estados, displays,
destinos, retornos, RNG y tempo bajo las entradas suministradas; repetición idéntica.
Tremolo reutiliza aritmética ya contrastada. Reloj/asignación/RNG, mapa del botón
Reverse, composición con lector/ADSR y salida siguen propios. No es equivalencia
acústica ni recuperación del ruteo completo del instrumento.
