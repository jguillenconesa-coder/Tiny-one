# Pocket One 0.25.0 — Spring 246

**Set 3 → FX → Spring 246**: Tone, Turns, Damping y Send, con Value FX,
automatización, controles contextuales y guardado en proyectos/slots/LIFT-DROP.
[Guía y límites](../spring246-native.md).

Inicializador y coeficientes originales legibles, sin sustituciones. El núcleo
coincide en 4096 bloques: 4088 activos y ocho de limpieza diferida. Estados,
display, contador y ocho memorias completas coinciden; repetición independiente
idéntica. El dominio usa slot 0 y workspace explícito, no el allocator original.

Activación/pánico del host limpian todo mediante una política propia. El reset
original conserva historiales y memoria intermedia y sigue contrastado aparte.
Volumen maestro después del bus y PDC fijo mantenidos. Pruebas del adaptador a
siete tasas, cola de reverb, controles extremos, selector/Configure/proxies,
persistencia, CC120 y renders 64/257. Carga de callback ampliada a 348 casos.

El CI macOS cambia a runner Intel manteniendo la compilación universal tras dos
cancelaciones por capacidad ARM64 antes de arrancar. Esto no demuestra ejecución
del slice ARM64, scanner de Ableton ni equivalencia acústica con el hardware.
**84/84 suites Linux**, standalone/VST3 y 348 cargas de callback sin heap
rastreado aprobados, además de sanitizadores de núcleo/adaptador.
[Validación](v0.25.0-validation.json). No se publica una release automáticamente.

Avance global estimado **46 % ±10 puntos**. Siguiente componente: CWO, sus tablas,
auxiliares e integración. Presets originales completos al final.
