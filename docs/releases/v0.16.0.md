# Pocket One 0.16.0 — Value Voice para los motores híbridos

Dr. Wave y Cluster admiten **set 4 → VALUE 246 VOICE**: modulación independiente
por voz de sus cuatro controles o ADSR, cantidad bipolar, tempo/free rate,
retrigger y FREE PHASE. Se reutilizan mandos MIDI y parámetros existentes, con
estado/slots/clipboard y sin sobrescribir controles base.
[Guía y límites](../value-hybrid246-native.md).

Se contrastan 4.096 llamadas adicionales con el firmware, repetidas en otro
directorio privado. Se conserva el wrap de los tres primeros colores de Dr. Wave
y el clamp de Cluster/ADSR. Los máximos verde/blanco de Dr. Wave pasan a 16383,
alineados con el rango observado. Los núcleos de audio de los dos motores no
cambian; pitch, reloj, mezcla y otros adaptadores siguen siendo híbridos.

65 suites Linux y 132 cargas de callback, además de sanitizadores, proxies/GUI,
guardado, release y renders independientes del buffer. [Validación](v0.16.0-validation.json).
También se corrige el orden de argumentos de `lipo` en el empaquetado macOS.
Un workflow manual permite verificar/empaquetar binarios existentes sin repetir
la compilación, conservando su versión real.
Las pruebas nativas/paquetes corresponden al CI de este commit; no equivalen a
una prueba de Ableton real o a comparación acústica con un OP-1. Los presets
originales completos siguen aplazados. No se publica una release automáticamente.
