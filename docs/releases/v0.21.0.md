# Pocket One 0.21.0 — Nitro Hybrid

**set 3 → NITRO HYBRID**: dos frecuencias, seguimiento bipolar de entrada y
resonancia, con Value FX, controles MIDI contextuales del host, automatización y
guardado de proyectos/slots/clipboard. Prioridad Nitro → Filter → Punch.
[Guía y límites](../nitro246-hybrid.md).

Se conserva la ruta mono legible y se sustituye explícitamente la mezcla/punteros
protegidos. Coincide con el oráculo condicionado en **262.144 muestras** y estados/
displays completos; repetición independiente idéntica. Esto no descifra L1 ni
demuestra coincidencia sonora con el Nitro original.

El bus comparte el PDC de Filter (~1,5 ms incluso en bypass), sin retardo adicional.
Se comprueban siete tasas, respuesta de ambos filtros, extremos de control,
pánico y bloques 64/257. La carga de callback se amplía a 252 casos.
[Registro de validación](v0.21.0-validation.json).

Se corrige la deriva de bits de Filter en MSVC expresando explícitamente su
desplazamiento aritmético. Los oráculos exactos de Filter y Nitro ya pasan en
Windows; el CI completo de compilación/empaquetado sigue en curso. Ableton real, calibración acústica y presets originales
siguen pendientes. No se publica release automáticamente.
