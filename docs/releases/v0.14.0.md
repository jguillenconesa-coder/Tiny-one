# Pocket One 0.14.0 — Dr. Wave híbrido

Dr. Wave pasa de núcleo aislado a motor tocable de seis voces, seleccionable en
**07 / DR. WAVE** o **BROWSE → Dr. Wave 246 Hybrid → Init / Dr. Wave**.
Set 1 expone los cuatro controles y set 2 la ADSR. Incluye bend/sustain, robo de
voz con relevo, MIDI por posición de muestra, estado/slots/clipboard y salida a
la frecuencia del host. Se añaden ocho parámetros de host.

El núcleo entero, sus 320 ondas generadas y transformaciones conservan sus
oráculos. Pitch, reloj, workspace por voz, ruteo ADSR, filtro/resampling y mezcla
son adaptadores propios. La clave OTP y L1 siguen pendientes; no se afirma
coincidencia acústica completa. [Guía y límites](../drwave246-hybrid.md).

El selector contiene siete motores. Por decisión del propietario, no se dedica
esta etapa a migraciones de sesiones históricas. Se prueba la persistencia de
las sesiones actuales. Los presets originales completos siguen aplazados; Init
es un punto de partida propio. El catálogo pasa a 69 sonidos incorporados.

Se añade una suite de motor y regresión de integración; el benchmark comprende
102 cargas e incluye el primer disparo Dr. Wave sin heap rastreado. Las pruebas
nativas de construcción/instalación no certifican por sí solas aceptación del
scanner de Ableton, rendimiento ASIO/CoreAudio ni igualdad con el instrumento.
[Registro de validación](v0.14.0-validation.json).
Los instaladores publicados anteriormente siguen identificados como 0.13.0;
esta entrega se empaqueta mediante el CI, sin publicar una release automáticamente.
