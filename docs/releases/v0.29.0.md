# Pocket One 0.29.0 — String 246

String sustituye el Karplus–Strong propio por una reconstrucción del waveguide:
ruido filtrado, línea de retardo, dos lecturas con interpolación de siete pasos,
amortiguación y caída de excitación. **524.288 muestras**, estados/RNG y dieciséis
memorias completas coinciden con el firmware, sin coeficientes sustituidos.

Cuatro controles originales, ADSR, seis voces, Mono/Legato/glide, Value Instrument/
ADSR, Random y Tremolo, automatización y guardado integrados. Las recetas propias
cambian su sonido. [Uso, procedencia y límites](../string246-native.md).

Reloj, pitch/cursor del host, scheduler, asignación y salida siguen siendo propios.
Random comparte el RNG de la excitación, incluso a profundidad cero. No se afirma
calibración acústica, validación Live ni réplica completa de presets originales.

**95/95 suites Linux**, 420 cargas sin heap rastreado, ASan/UBSan y revisión
visual pasan. Verificadores de String y regresión FM aprobados en Linux,
Windows/MSVC y macOS Intel; plugins e instaladores completos en curso. [Evidencia de validación](v0.29.0-validation.json). Se mantiene el volumen maestro
tras el bus y su PDC. Avance de planificación: **54 % ±10 puntos**.
