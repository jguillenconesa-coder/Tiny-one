# Pocket One 0.22.0 — Delay 246

**set 3 → DELAY 246** añade Size, Speed, Feedback y Mix/Send, con Value FX,
automatización, MIDI contextual del host y guardado en proyectos/slots/clipboard.
Los cuatro botones de FX comparten la misma fila. Prioridad bajo automatización
simultánea: Delay → Nitro → Filter → Punch. [Guía](../delay246-native.md).

El núcleo mono, su reset y los 225 coeficientes legibles coinciden en **262.144
muestras**, estados/displays y ocho memorias circulares completas. Repetición
privada independiente idéntica. No se sustituyen coeficientes de esta ruta.
Workspace, clock y bus de salida siguen siendo adaptadores propios.

No añade retardo al PDC existente (~1,5 ms incluso en bypass). Pruebas a siete
tasas, impulso con eco causal, Mix cero del núcleo, pánico, estados, GUI y bloques
64/257. Carga de callback ampliada a 276 casos. [Registro](v0.22.0-validation.json).

El CI de esta entrega debe validar los paquetes Windows/macOS. Ableton real,
ruteo estéreo original y calibración acústica siguen pendientes. Presets originales
al final; no se publica release automáticamente.
