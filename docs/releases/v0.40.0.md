# 0.40.0 — Fuente drum compartida y 24 regiones

LOAD SOURCE permite usar los primeros 12 segundos de una sola grabación para
24 regiones editables. Las doce voces leen el mismo PCM con controles independientes;
los kits de muestras independientes siguen disponibles. Shift + IN captura hacia
el sampler drum nativo y conserva su destino. Proyectos, slots y clipboard guardan
el audio y las regiones, sin depender del archivo importado.

La división inicial en partes iguales, conversión/importación y composición son
propias. Se reutiliza el lector FIR ya contrastado; no hay un nuevo oracle del
firmware ni prueba de equivalencia acústica. La dinámica original sigue pendiente.
