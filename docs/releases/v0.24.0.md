# Pocket One 0.24.0 — Phone 246

**set 3 → FX → Phone 246**: Tone, Phonic, Baud y Telematic, con Value FX,
automatización, MIDI contextual del host y guardado en proyectos/slots/clipboard.
El selector conserva las opciones anteriores. [Guía y límites](../phone246-native.md).

El callback mono coincide en **262.144 muestras**, estado de 140 bytes, display
y ocho capturas completas de los buffers. Tablas generadas desde fragmentos
legibles y repetición privada independiente idéntica. El centinela máximo se
contiene mediante dos guardas explícitas; no se reconstruye el allocator original.

Soft reset original y pánico completo del host diferenciados. Pruebas a siete
tasas, salida solo procesada, controles extremos, selector/Configure/proxies,
estados, CC120 y buffers 64/257. Carga de callback ampliada a 324 casos.
[Registro](v0.24.0-validation.json). Comparte PDC sin otro retardo (~1,5 ms).

Grid 0.23 pasó las tres plataformas con sus paquetes; el nuevo código requiere
su propio CI. Ableton real, ruteo estéreo y comparación acústica siguen pendientes.
Presets originales completos al final; no se publica release automáticamente.
