# Pocket One 0.38.0 — Value y Random de batería

Drum 246 y D-box incorporan Value Voice y Random de ocho destinos por golpe,
dos bancos de Value, automatización, proyectos, slots/clipboard y proxies sin
editor. El destino ADSR se muestra OFF y no altera el audio ni el estado del LFO.
No se conecta la envolvente común a la dinámica de batería.

**16384 llamadas originales** contrastan ambos callbacks, tipos y descriptores,
con estado/display/RNG/destinos/retornos/tempo completos y repetición idéntica.
La dinámica, afinación, conversiones de controles, clock, allocator y salida siguen
propios. No se ha recuperado el productor de ganancia ni la voz completa original.

[Uso y contrato](../drum246-modulation.md) · [Validación y CI](v0.38.0-validation.json).
El CI completo anterior de 0.37.0 pasó Linux, Windows y macOS universal, runtime Intel.
**117/117 suites Linux**, cinco suites independientes, ASan/UBSan y **630 cargas
sin heap rastreado**, incluidas 48 nuevas de LFO drum/D-box. Estado/audio, proxies,
64/257 frames, rechazo de ENV, cola y vistas aprobados. CI nativo y paquetes nuevos
pendientes del push; no se publica release.

Sigue el estudio de productores/ruteo y los moduladores pendientes, fuente única
drum, Pulse/L1, calibración acústica, Ableton real, ejecución arm64 y presets
originales completos al final. Estimación **≈67 % ±10 puntos de planificación**,
sin atribuir un porcentaje de fidelidad sonora.
