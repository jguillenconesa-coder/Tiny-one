# Pocket One 0.30.0 — DNA Hybrid 246

Noveno motor: **DNA Hybrid**, con cuatro controles originales, ADSR, seis voces,
Mono/Legato/glide, Value Instrument/ADSR, Random y Tremolo, automatización y guardado.

Se contrastan 4096 bloques / 524288 muestras, seis estados vivos, RNG, onda y RAM
completas, más 8192 callbacks de modulación. La coincidencia está condicionada a
la identidad y memoria suministradas: **el plugin usa una identidad virtual fija y
ceros fuera del pool de voces**, no la identidad/RAM del OP-1 del vídeo.

Una prueba original aislada confirma que cambiar solo esa RAM cambia el audio.
No se presenta el perfil virtual como calibrado acústicamente ni como memoria
L1 descifrada. [Uso y límites](../dna246-hybrid.md).

Reloj/pitch/scheduler/salida siguen con adaptadores propios. Los presets originales
completos quedan para el final. Avance de planificación **≈56 % ±10 puntos**.
[Evidencia](v0.30.0-validation.json). No se publica una release automáticamente.

Validación local: **98/98 suites**, **444 cargas sin heap rastreado**, ASan/UBSan
y revisión visual. [Núcleo/modulación DNA](https://github.com/jguillenconesa-coder/Tiny-one/actions/runs/41482204653)
y regresiones FM/String pasan en Linux, Windows y macOS Intel.
[Plugins e instaladores completos](https://github.com/jguillenconesa-coder/Tiny-one/actions/runs/41482204475)
siguen en CI; no implica validación en Ableton real.
